# 🐦 Flappy Bird

Классическая аркадная игра Flappy Bird, реализованная на Python с использованием библиотеки Pygame.


## ✨ Особенности

- 🎯 Простой, но захватывающий геймплей
- 📊 Система подсчета очков
- 🔄 Механика рестарта после проигрыша
- 🎨 Простая, но приятная графика
- 📱 Адаптивное управление
- ⚡ Реалистичная физика полета

## 🕹️ Управление

| Действие | Клавиша |
|----------|---------|
| Прыжок | `ПРОБЕЛ` или `↑` (Стрелка вверх) |
| Начать игру | `ПРОБЕЛ` |
| Рестарт | `ПРОБЕЛ` (после Game Over) |
| Выход из игры | Закрыть окно |

## 📋 Системные требования

- Python 3.6 или выше
- Pygame библиотека
- Операционная система: Windows / macOS / Linux
